# Animal Tier List — игра-викторина про животных

Ребёнок расставляет животных по уровням S–A–B–C–D в выбранной категории (вес, скорость, сила укуса…), а потом видит оценку, реальные цифры, наглядный масштаб и факты с источниками.

## Как запустить

Открыть `index.html` двойным кликом. Интернет не нужен. Работает на компьютере и телефоне (от 360 px).

Чтобы открыть на телефоне: скопировать всю папку в облако (Google Drive, Яндекс Диск) или на сайт — главное, чтобы файлы лежали вместе.

## Вызов друга (соревнование)

После результата — кнопка «📤 Вызвать друга». Она делает ссылку, в которой зашиты те же животные, те же границы тиров, твоё имя и счёт. Друг открывает ссылку, играет тот же набор и видит, кто набрал больше; кнопка «Ответный вызов» шлёт результат обратно. Сервера нет, аккаунтов нет — всё в ссылке.

**Ссылка работает, только когда игра лежит в интернете** (файл с диска у друга не откроется). Самый простой бесплатный способ — GitHub Pages:
1. Завести аккаунт на github.com, создать репозиторий (например `animal-tier-list`), галочка Public.
2. Загрузить в него всю папку игры (кнопка «Add file → Upload files», перетащить файлы).
3. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
4. Через минуту игра доступна по адресу `https://<твой-логин>.github.io/animal-tier-list/` — его и открывать на телефоне.

Обновил данные → снова загрузил изменённые файлы в репозиторий.

## Что где лежит

| Файл | Что это |
|---|---|
| `index.html` | страница игры |
| `style.css` | оформление |
| `game.js` | логика: выбор животных, перетаскивание, подсчёт очков, звук |
| `results.js` | экран результатов: оценка, диаграмма, карточки фактов, попап |
| `visual.js` | блок «Наглядно»: сцена в масштабе, весы, гонка, линейка |
| `data/animals.json` | **животные и все цифры** — главный файл данных |
| `data/categories.json` | **категории**: какая метрика, единица, фраза сравнения, тип картинки |
| `data/data.js` | те же данные в виде, который читает браузер с диска. **Генерируется, руками не править** |
| `data/merge.py` | собирает `animals.json`, `data.js` и `SOURCES.md` из сырых файлов `data/raw/` |
| `data/fetch_media.py` | качает фото с Wikimedia Commons и сводки из русской Википедии |
| `img/*.jpg` | фото животных (320 px), `img/credits.json` — авторы и лицензии |
| `SOURCES.md` | таблица «животное → метрика → ссылка → дата проверки» |

## Как поправить цифру

1. Открыть `data/animals.json` в любом текстовом редакторе (Блокнот подойдёт).
2. Найти животное по `"id"` или `"name_ru"`, в `"metrics"` изменить `"avg"` (среднее) или `"max"` (рекорд), обновить `"source"`.
3. Запустить `data/merge.py` — **нет**, это пересоберёт файл из сырых данных и затрёт правку. Вместо этого:
   - либо править `data/raw/*.json` (сырые файлы агентов) и потом запускать `python merge.py` из папки `data`;
   - либо, если Python нет, править сразу **два** файла: `data/animals.json` и ту же строку в `data/data.js`.

## Как добавить животное

В `data/raw/new_a.json` (или любой `new_*.json`) добавить запись по образцу:

```json
{
  "id": "red_fox",
  "name_ru": "Лисица",
  "name_en": "Red fox",
  "latin": "Vulpes vulpes",
  "emoji": "🦊",
  "fun_fact": "Лисица слышит, как мышь шуршит под снегом.",
  "hint": "Рыжий хитрец из сказок, размером с небольшую собаку.",
  "metrics": {
    "weight_kg":      { "avg": 6,  "max": 14, "estimated": false, "source": "https://en.wikipedia.org/wiki/Red_fox", "note": "" },
    "speed_kmh":      { "avg": 50, "max": null, "estimated": false, "source": "https://en.wikipedia.org/wiki/Red_fox", "note": "" },
    "lifespan_years": { "avg": 3,  "max": 15, "estimated": false, "source": "https://en.wikipedia.org/wiki/Red_fox", "note": "" }
  }
}
```

Правила:
- Метрику без надёжного источника **не добавлять** — животное просто не попадёт в эту категорию.
- `"estimated": true` — если цифра расчётная, а не измеренная; в игре покажется звёздочка.
- Ключи метрик: `bite_force_n`, `tooth_length_cm`, `teeth_count`, `loudness_db`, `deaths_per_year`, `weight_kg`, `height_m`, `length_m`, `speed_kmh`, `lifespan_years`, `sleep_hours`, `heart_bpm`, `gestation_days`, `dive_depth_m`.

Потом из папки `data`:
```
python merge.py
python fetch_media.py
python merge.py
```
Первый `merge.py` собирает данные, `fetch_media.py` качает фото и сводку (нужен интернет), второй `merge.py` прикрепляет их.

## Как добавить категорию

В `data/categories.json` добавить блок:

```json
{
  "id": "jump",
  "metric": "jump_length_m",
  "title": "Прыжок в длину",
  "question": "Кто прыгает дальше всех?",
  "unit": "м",
  "compare_phrase": "прыгает в {x} раз дальше человека",
  "visual": "scale"
}
```

- `metric` — ключ, который должен быть в `metrics` у животных.
- `compare_phrase` — `{x}` заменится на «3 раза» / «примерно 40 раз».
- `visual` — как рисовать блок «Наглядно»: `silhouettes` (в масштабе, с зумом), `balance` (человечки), `race` (гонка), `lifelines` (полоски), `scale` (линейка).
- `ref_id` — с кем сравнивать, если не с человеком (например `"great_white_shark"`).
- Категория появится на главном экране сама; если животных с этой метрикой меньше, чем выбрано (5/8/10), кнопка будет серой.

## Откуда цифры

Каждая цифра — со ссылкой в `SOURCES.md`. Приоритет: английская Википедия → Nat Geo / Smithsonian / зоопарки / Guinness → научные статьи. Укус хранится в ньютонах: популярные «PSI» на деле — фунты силы, переведены ×4,448. Подводные децибелы (киты, дельфины) переведены в воздушный эквивалент (−61,5 дБ).

Фото — Wikimedia Commons, только свободные лицензии (CC BY, CC BY-SA, Public Domain); автор и лицензия — в попапе и в `img/credits.json`.

## Подсчёт очков

Животные раунда (с человеком) сортируются по цифре и делятся на 5 равных частей: верхняя — S, дальше A, B, C, D. За карточку в своём уровне 2 очка, в соседнем 1, дальше 0. Подсказка срезает максимум на 10 %. Звёзды: ≥90 % — три, ≥60 % — две. Лучший результат по категории хранится в памяти браузера.
